Keep this file and CLAUDE.md identical. Read ../../AGENTS.md and ../AGENTS.md.

This registry owns user-visible Blackcrab names in the selected shared runtime,
contracts and provider settings consumed by the iOS app. Original upstream source
and licenses remain in the authenticated preparation and consumer original-files.
Do not hand-edit vendor source or regenerate inventories to conceal changes.

Regenerate with pinned Node and `build-registry.mjs <authenticated-preparation>`.
It verifies the original preparation, composes existing owned-cloud patches in
memory, then records exact literal changes and reviewable diffs. Review every
changed patch before accepting the registry. Protocol/schema/package identifiers
and actual third-party T3 Chat or T3 Code for GitHub names remain unchanged.
The tunnel-limit message must report the server limit and a real recovery action;
do not invent Blackcrab prices or retain the inherited T3 subscription upsell.

consumer.mjs applies type, cloud and copy layers in order. For overlapping files,
retain the earliest original, reconstruct each intermediate layer, and compare
the final result with the packaged source. Never overwrite original provenance
with an already-patched intermediate. Consumer verification, source tests and
an actual generated/bundled runtime audit are separate from OTA installation.
