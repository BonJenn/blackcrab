Inactive source integration, not packaged or release acceptance. The predecessor chain is active host21, boot5, owned-auth, then the existing identity-v2 HTTP candidate. `registry.json` records the exact narrow successor bytes. Original source remains MIT-licensed; adjacent source records retain the pinned target and archive provenance.

The original CLI provides that same object to `ServerConfig`; cloning or serializing it cannot transfer capture. No secret getter, renderer constructor, HTTP configuration input or native-helper path is added.

The concrete HTTP successor uses this capture for v2, validates the original environment descriptor on every request, refuses service downgrade to v1, and leaves Direct's v1 branch unchanged. The listener retains the original service configuration, including LAN/private-network policy; the captured native control origin is canonical loopback. Request headers and query identity cannot choose it. This replaces the optional interface-only issuer for the concrete path; installing an interface is not evidence of native authority.
