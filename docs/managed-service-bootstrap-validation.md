# Native-issued service bootstrap

This increment wires private native issuance into the original Node service launcher and server configuration. It does not activate a background service or certify remote-service parity. The genuine profile4 artifact, native selection/migration, OS-unit lifecycle and installed remote-client acceptance remain subsequent gates.

The fixed headless Root entry runs before Tauri initialization. It accepts one exact private argument and derives its owner, selected manifest and helper identity from the installed executable layout and compiled trust anchor. Native publication refuses Direct migration and replacement of an existing binding. The issuer verifies the selected payload and required boot, authentication, launcher and concrete backend source records before reporting ready; the launcher awaits that ready response before original database recovery. Private bounded FD0 delivery carries authentication and binding only. Original service.env/CLI network precedence and IPC3 prepared/committed activation remain in use.

The server captures the actual resolved configuration object and immutable FD0 identity in a private WeakMap. Its v2 route signs a fresh challenge with the captured manifest, version, environment and canonical loopback control origin, independently of the LAN listener. Direct v1 remains unchanged; service downgrade is refused. Owned web/headless children watch the original IPC lifetime before starting the server, including already-disconnected refusal. Renderer settings, HTTP headers and discovery cannot install capture or choose a helper path.

Issuer epochs are durably prepared, issued and retired. Failed or uncertain writes poison the session; authentication delivery is not HTTP readiness. An interrupted same-boot issuance remains unavailable until whole-job quiescence can be proven. A verified different kernel boot can retire the old uncertain epoch without replaying its envelope. Neither persisted PIDs nor absence of a SQLite lock authorizes recovery or signaling. Generation is an issuance/context fence, not a field in the v2 proof transcript.
