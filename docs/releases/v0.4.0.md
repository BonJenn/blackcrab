# Blackcrab 0.4.0

Blackcrab 0.4.0 brings the full managed desktop workspace and its background
service into the Mac app, alongside the existing local session interface.

## Included

- A packaged full desktop workspace for managed projects and agent threads.
- Background-service setup and controls, with desktop attachment and reconnection.
- Shared project, Git, terminal, approval and agent workflow interfaces.
- Blackcrab-owned account, hosted-app and remote connection configuration.
- Preserved app identity and updater key for existing Blackcrab installations.

## Download and upgrade

This release is **Apple-silicon Mac only (M-series)**. Download the 0.4.0 DMG or
use the app's updater once it detects the new release. Intel Mac, Windows and
Linux users should use the previous releases; no 0.4.0 installer for those
platforms is included.

Keep your existing Blackcrab data. The release does not require deleting saved
sessions or app settings. Back up important work before testing the new managed
workspace and service controls.

## Validation status

The release is published for owner testing. Automated checks and artifact
signature/notarization verification are separate from the manual app launch,
service lifecycle and upgrade-retention tests, which the owner will perform
after publication. Full end-to-end remote and notification validation remains
ongoing; this release is not a declaration of completed T3 parity.

Blackcrab Remote is in private iOS TestFlight testing. This Mac release does not
publish a new mobile build or open public App Store access.
