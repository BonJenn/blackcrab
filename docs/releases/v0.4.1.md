# Blackcrab 0.4.1

This Apple-silicon Mac patch improves Full desktop startup detection and error
reporting following the 0.4.0 owner test.

- Full desktop now queries the native app for availability. A missing JavaScript
  runtime marker no longer incorrectly labels the desktop package as absent.
- Startup failures retain specific package, storage and lock errors in Settings.
  Native command errors are displayed instead of a generic failure message.
- Existing session data, app identity, updater key and bundled workspace/service
  payloads are preserved. No cache deletion or permission repair is required.

The client detection regression is covered by automated tests. Whether it
resolves the reported work-Mac failure still requires testing on that Mac.
This patch does not establish completed desktop, mobile or remote parity.

Update from 0.4.0 using Blackcrab's updater or the new DMG once this release is
published. Open Settings → Full desktop → Open full desktop. If it remains
unavailable, report the complete status and error text shown there. The 0.4.0
release files remain unchanged. No new iOS TestFlight build is included.
