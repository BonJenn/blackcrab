# Blackcrab shared product text

The native app imports shared connection diagnostics, relay error presentation,
project actions and provider settings. Branding only its app screens leaves
upstream product names in those runtime messages. This registry adapts that
shared text after the existing owned-cloud changes.

Generate from the authenticated preparation with `node
mobile-experience/product-copy/build-registry.mjs <preparation>`, then regenerate
consumers with `mobile-experience/build-consumers-cli.mjs`. The original source,
each ordered patch and final inventory remain verifiable. Do not edit the
consumer inventory by hand.

The inherited tunnel-limit upsell is replaced with the actual server limit and
an instruction to unlink an environment. This does not implement billing or
change quota enforcement. T3 Chat integration/theme labels, the actual T3 Code
for GitHub App name, and t3.json schema documentation remain third-party names.
